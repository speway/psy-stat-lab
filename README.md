# СтатЛаб

Интерактивная статистическая лаборатория для студентов-психологов. Проект помогает подобрать метод анализа, сформулировать гипотезы, прочитать результаты SPSS и jamovi и корректно описать статистический вывод.

## Разделы

- основы статистического анализа;
- критерии и проверка гипотез;
- ANOVA, регрессия и статистические модели;
- психометрика и стандартизация;
- факторный, кластерный и другие многомерные методы;
- практические исследовательские кейсы.

## Локальный запуск

```bash
npm ci
npm run dev
```

Для проверки сборки под Vercel:

```bash
npm run vercel-build
```

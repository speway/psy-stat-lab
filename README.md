# СтатЛаб

Интерактивная статистическая лаборатория для студентов-психологов. Проект помогает подобрать метод анализа, сформулировать гипотезы, прочитать результаты SPSS и jamovi и корректно описать статистический вывод.

## Разделы

- основы статистического анализа и формы распределений;
- интерактивная песочница: сравнение 2 выборок, мощность $1 - \beta$, перекрытие кривых (Overlap), выбросы и психометрика;
- критерии и проверка гипотез ($H_0$ и $H_1$, предпосылки, ловушки);
- пошаговые гайды по процедурам SPSS и jamovi с интерактивной анатомией таблиц вывода, синтаксисом и кодом на Python;
- ANOVA, регрессия и статистические модели;
- психометрика, нормы, стандартизация баллов и формула Спирмена — Брауна;
- факторный, кластерный и другие многомерные методы;
- практические исследовательские кейсы и генератор отчётов по стандартам APA 7 / ВАК.
